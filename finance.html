How to Set Up Financial in BrainBell

Simple step-by-step guide

  1. Choose Financial Category
    For example, select "bills" from the available categories.
  2. Click + Button
    Tap the "+" button to add a new financial reminder.
  3. Select Bill Type
    You can choose any bills to set up, for example: gas. If you can't find it in the options, you can choose "others".
  4. Enter Details
    Write the title and the amount to pay. For example: AGL Gas $160.
  5. Enable Recurring
    Click recurring so the reminder can set up for every time you need to pay.
  6. Set Up Alert
    Set up alert to remind how many days or weeks before the due date. For example, one week before.
  7. Save Your Reminder
    Then click save to create your financial reminder.
  8. View Your Trackers
    Then you can see all your financial reminders appear in the financial tracker.
