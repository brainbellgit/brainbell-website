How to Set Up Study Planner in BrainBell

Simple step-by-step guide

  1. Add Subject
    • Click the plus ( + ) button in the subjects section
    • Add the Name, Year, Semester, Lecturer and Lecturer Details (Optional)
    • It will automatically put in a semester duration for you, however you are able to adjust it by clicking on the semester duration buttons (from start to end)
    • You are also able to add study resources
  2. Add Task (I.e Assignments, Exams, Study, Labs, etc)
    • Click the ( + ) button in the study section to open the Add Task Sheet
    • If no subjects have been created yet, the app will prompt you to create one and open the subjects tab
    • Enter the title of the task
    • Select the type of the task from the drop down (I.e Assignment, Exam, Study, Lab, Other)
    • Select the start Date & Time of the task
    • Select the end Date & Time of the task
    • Enable Milestone/Goal - This will allow you to set the task you are making as a goal you might want to celebrate in the future. When this milestone is completed, the app will congratulate you as well
    • Set alerts for this task by clicking the default time and selecting what time to notify you about the task. Feel free to add multiple
    • Once done, click save
  3. Complete a Task
    • When you want to set a task as completed on your study planner, you will see the reminder in the today section where you can click it
    • Here you can complete, edit, or delete the task
    • Clicking complete will complete the task so that you can view your completed tasks
    • If the task was a milestone, it will also show as completed in the Milestones & Goals section
  4. See All Your Tasks (Calendar)
    • Whenever you create a task, you will be able to see the tasks you have set for other days in the today section by clicking on the day on the calendar
